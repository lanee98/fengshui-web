# 访谈执行手册（A4 版，可直接打印）

> 目的：为 18 条规则的 severity（high/medium/low）和 default_on（默认开启与否）收集真实用户证据。
> 数量：设计师 2–3 位 + 业主 3–5 位。半信半疑的普通业主是最有价值的样本。
> 时长：每人 25–35 分钟。可当面或微信语音，**必须记录原话**。

---

## 一、开场（2 分钟）

「我们在做一个装修辅助系统，里面内置了 18 条常见的家居布局讲究，想听听你实际在不在意。没有对错，你说什么我们都照实记录。」

## 二、热身（3 分钟）

1. 你装修时（或想象装修时）最在意什么？
2. 有没有听过家里长辈讲什么摆设讲究？

## 三、核心：逐条过 18 条规则（15–20 分钟）

拿着下面的清单，每条问三个问题，当场在表格里记：

**问法（固定三连）**
1. 「这条你听说过吗？」——听说过 / 没听过
2. 「你在意吗？」——**A 必须改 / B 提一下就行 / C 无所谓**
3. 「为什么？能说说理由吗？」——**记原话**

## 四、业主附加两问（5 分钟）

1. 「如果系统检测到问题，你希望它**自动改方案**，还是**先提示你来决定**？」
2. 「一个装修工具有风水参考功能，会影响你用它吗？」

## 五、设计师附加两问（5 分钟）

1. 「实际项目里，客户最常提这 18 条中的哪几条？」
2. 「一般怎么化解？」（核对修正动作：加隔断/移家具/门帘，是否与行业做法一致）

## 六、收尾开放题（2 分钟）

「还有哪些你们实际在意、但清单上没有的？」——出现 2 次以上的候选进规则库 v2。

---

## 七、记录与回填

**每条访谈单独建一个 JSON**，存到 `rules_interviews/` 文件夹（与 rules/ 平级），命名 `interview_01.json`、`interview_02.json`…格式：

```json
{
  "interview_id": "interview_01",
  "role": "设计师",
  "date": "2026-10-XX",
  "collected_by": "成员名",
  "items": [
    { "rule_id": "FS-BED-001", "heard": true, "attitude": "A", "quote": "床头不靠墙睡觉不踏实，我一般都劝客户贴墙" }
  ],
  "extra_rules": [],
  "notes": ""
}
```

**severity 回填规则**（交给艺云汇总）：
- ≥60% 选 A → 维持或升为 high
- 多数选 B → medium
- 多数选 C → 降 low，且 `default_on` 讨论是否改 false

**禁止事项**：不要引导性提问（不要说「这个是不是很忌讳？」）；不要当场跟受访者争论迷信与否；原话带方言/口语照记。
