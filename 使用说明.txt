启动方法
1. 完整解压 ZIP，不要直接在压缩包内运行。
2. 双击“启动风水审查平台.cmd”。
3. 浏览器自动打开 http://127.0.0.1:5000 。控制台窗口需保持打开。
4. 按 Ctrl+C 或关闭控制台停止服务。若已有同一平台运行，启动脚本会直接打开它。

启动脚本使用解压目录的相对路径，项目可放在其他文件夹。
优先复用本机已有的 Flask 环境；你的电脑可使用 D:\anaconda3\python.exe。
其他电脑推荐安装 Python 3.9 或以上版本。没有 Flask 时，脚本会在项目内建立
.venv 并安装 requirements.txt，首次安装需要联网。ZIP 不包含 Python 运行时。
也可自行安装依赖后，在项目目录执行 python start.py。

本包已包含的功能
- 导入图片后自动提取墙线、常见家具线稿符号和门窗候选。
- 生成平面图 / 原图叠加切换；修改、删除、补画墙线及家具。
- 家具类型、尺寸、位置与角度可修正。识别结果需要核对。
- 图片比例无法仅靠像素准确确定，需标定一段实际长度后进入 3D。
- 彩色 3D 家具；点击选中后用平移箭头、中心方块、旋转环调整。
- 保留数值移动、角度调整、一键尝试修复、复检、撤销与保存。
- 左键拖动空白区域旋转视角，Shift＋左键拖动平移视角。
- 平面图页面分别用“修改前平面图”“修改后平面图”按钮切换。
- 3D 修改同步到修改后平面图；原始摆位在进入 3D 时保留。

识别范围与数据保存
自动识别使用本地像素和常见线稿符号筛选，不是通用 AI 识图模型。
复杂扫描图、特殊家具符号或与墙体粘连的图形可能漏识别，需要手动核对、补充。
旧户型此前没有保存的初稿无法追溯；程序会说明，并从首次保存开始保留两个版本。
户型、上传底图与前后版本保存在浏览器本地存储，不在项目文件夹中。
因此本 ZIP 不包含你在浏览器里导入的个人户型数据；换电脑或换浏览器需要重新导入。
在同一浏览器访问同一个 http://127.0.0.1:5000 地址可继续读取已保存的户型。
